# Repository ownership and publishing

- The authorized GitHub repository is `https://github.com/maponyatp/ecommerce-laravel.git`.
- Use Maponya's `origin` only for GitHub synchronization. Do not add, fetch, pull or push the former `liberusoftware/ecommerce-laravel` upstream unless the user explicitly changes this instruction.
- Preserve upstream copyright/license notices; attribution is not a synchronization instruction.
- Never commit operational backups, `work/`, database copies, production environment files, logs or credentials.
- This source snapshot is a review branch, not a deployment approval. Do not automatically replace `main`, resolve existing conflicts by discarding either side, or deploy unfinished modules.
- Check current production release records before describing locally present modules as live features.
